## Dataset Description
This dataset contains video game sales data from 1980 to 2020.
It includes the following columns:
- **Rank** - Ranking of the game by global sales
- **Name** - Name of the video game
- **Platform** - Platform the game was released on (PS2, Wii, etc.)
- **Year** - Year the game was released
- **Genre** - Genre of the game (Action, Sports, etc.)
- **Publisher** - Publisher of the game
- **NA_Sales** - Sales in North America (millions)
- **EU_Sales** - Sales in Europe (millions)
- **JP_Sales** - Sales in Japan (millions)
- **Other_Sales** - Sales in other regions (millions)
- **Global_Sales** - Total worldwide sales (millions)

## Purpose of Using This Dataset
- Video games is an interesting and relatable topic
- It contains a mix of numeric and categorical columns perfect for EDA
- It allows analysis across multiple dimensions: genre, platform, region and time
- It helps understand real-world sales trends in the gaming industry
